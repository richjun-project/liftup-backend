# 앱 기능 ↔ 채팅(AI PT) 대응표

2026-11-21 대표: "우리 기능은 채팅으로 안 되는 게 없게, 리스트 체크해서 다 되게, 에이전트 서비스답게".
앱 화면 24개(`lib/features/*/presentation/screens`)와 서버 API 를 보고, 사용자가 할 수 있는 일마다 채팅에서 어떻게 하는지 적었다.
새 기능을 만들면 여기에 한 줄을 더하고, 채팅으로 할 수 있게 도구를 같이 만든다. 테스트 `ChatFeatureToolsTest` 가 이 문서에 모든 도구 이름이 있는지 확인한다.

## 보기 (읽기 도구)
| 앱에서 | 채팅에서 | 도구 |
|---|---|---|
| 홈 — 오늘 운동(Day·종목·무게) | "오늘 뭐 해?" | `get_today_workout` |
| 플랜 상세 — 주간 Day 구성 | "이번 주 플랜 보여줘" | `get_plan_overview` |
| 기록 — 지난 운동 | "지난주에 뭐 했지?" | `get_recent_workouts` |
| 종목 기록·1RM 추세 | "벤치 늘었어?" | `get_exercise_history` |
| 통계 탭 — 볼륨·횟수·PR | "요즘 강해지고 있어?" | `get_progress_stats` |
| 회복 탭 — 부위별 회복 | "하체 해도 돼?" | `get_recovery_status` |
| 식단 탭 — 오늘 먹은 양·남은 양 | "단백질 얼마나 먹었어?" | `get_nutrition_today` |
| 운동 검색 | "무릎에 덜 부담되는 하체 운동" | `search_exercises` |
| 프로그램 둘러보기 | "더 쉬운 플랜 있어?" | `get_plan_options` |

## 바꾸기·기록하기 (행동 도구 — 앱 상태가 바뀐다)
| 앱에서 | 채팅에서 | 도구 |
|---|---|---|
| 운동 교체 | "스쿼트 다른 걸로 바꿔줘" | `swap_exercise_in_plan` |
| 오늘 할 Day 바꾸기 | "오늘 하체 날로 할래" | `set_today_workout_day` |
| 장비 설정 | "집에 덤벨만 있어" | `set_available_equipment` |
| 운동 알림 시각 | "저녁 8시에 알려줘" | `set_workout_time` |
| 트레이너 체크인 끄기·켜기 | "메시지 그만 보내" | `set_coach_messages` |
| 식단 기록(사진) | 사진을 보내면 분석·저장 | (채팅 사진 분석) |
| 식단 기록(글) — **새로** | "점심에 김치찌개랑 밥 한 공기 먹었어" | `log_meal` |
| 식단 기록 지우기·고치기 — **새로** | "아까 그거 안 먹었어" / "밥 반 공기였어" | `delete_meal_log` (+ `log_meal`) |
| 프로필 — 체중·키·나이·목표·수준 — **새로** | "요즘 72kg이야", "근육 키우고 싶어" | `update_my_profile` |
| 운동 계획 — 주당 일수·운동 시간 — **새로** | "주 3일만 할 수 있어" | `update_my_profile` (+ `get_plan_options`) |
| 부상 — **새로** | "무릎을 다쳤어" (플랜에서 무릎 부담 운동이 빠진다) | `update_my_profile` |
| 트레이너 고르기(말투) — **새로** | "좀 더 엄하게 해줘" | `update_my_profile` |
| 플랜 바꾸기 — **새로** | "더 쉬운 플랜으로 바꿔줘" | `get_plan_options` → `change_plan` |
| 플랜 쉬기·다시 시작 — **새로** | "다음 주 출장이라 쉴게" | `pause_or_resume_plan` |
| 밖에서 한 운동 기록 — **새로** | "오늘 헬스장에서 스쿼트 100kg 5×5 했어" | `log_completed_workout` |
| 코치가 한 일 되돌리기(코치 활동 화면) — **새로** | "아까 바꾼 거 원래대로" | `undo_last_coach_change` |
| 코치 기억 보기·지우기 | "나 아침형이야", "그거 잊어줘" | `remember`, `forget` |
| 오늘 운동 시작 | 답 아래 [오늘 운동 시작] 버튼 | `[[START_TODAY_WORKOUT]]` |

## 채팅으로 안 하는 것 (이유)
| 기능 | 이유 | 채팅에서 |
|---|---|---|
| Pro 결제 | 스토어 결제는 스토어 화면에서만 된다 | 혜택을 설명하고 결제 화면으로 안내 |
| 계정 삭제 | 되돌릴 수 없어 화면에서 직접 확인받는다 | 위치를 알려 준다 |
| 새 AI 맞춤 플랜 만들기 | 만드는 데 약 1분(채팅 답 한도 21초) | [[OPEN_PLAN]] 버튼 |
| 운동 중 세트 체크·휴식 타이머 | 운동 화면의 실시간 조작 | 운동 화면 |
| 로그인·회원가입·앱 언어 | 계정·기기 설정 | — |
