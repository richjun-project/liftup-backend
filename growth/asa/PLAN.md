# Apple Search Ads 소액 테스트 — 실행안(2026-11-05, 대표 결정 대기)

10-27 제안의 실행 버전. 대표가 계정만 열면 같은 날 시작할 수 있게 키워드·입찰·측정·중단 기준을 미리 정해 둔다.

## 왜 지금
- 무료 경로(이름·부제 ASO, 일본어·한국어 GEO, Threads 한·일, 피처링 추천, 인앱 이벤트)를 모두 열었지만 실가입은 주 1~2명. 결제·체험 퍼널을 잴 표본이 안 생긴다.
- 한국 App Store 검색은 퍼널이 살아 있다: 10/28~11/03 검색 노출 199 → 탭 3 → 첫 다운로드 2(새 스크린샷 뒤 탭률 0% → 1.5%). 막힌 곳은 노출 순위(큰 검색어 50위 밖)다. 광고는 그 검색어 맨 위 한 칸을 산다.
- 1.1.38 부터 앱이 AdServices 귀속 토큰을 RevenueCat 에 보낸다(앱 6f0a1c1) → 광고 설치가 체험·결제까지 이어서 보인다. **광고 시작은 1.1.38 공개 뒤**가 좋다(그 전 설치는 ASA 콘솔 숫자로만 본다).

## 구성(Advanced, 한국만, 검색 결과 광고)
- 예산: 하루 ₩10,000 × 14일, 총 상한 ₩140,000(캠페인 총예산으로 걸어 넘지 않게).
- 광고 그룹 1 — AI 의도, 정확 일치, 최대 CPT ₩800: AI PT · AI 피티 · AI 트레이너 · AI 퍼스널 트레이너 · AI 헬스 트레이너 · AI 운동 · AI 헬스 · AI 운동 루틴 · AI 운동 추천 · AI 홈트 · AI 코치 · 헬스 코치
  (지금 자연 순위: AI 퍼스널 트레이너 3위·AI 운동 루틴 5위·AI 운동 추천 13위 — 상위권은 광고 효율 비교용으로 남기고, 나머지는 50위 밖이거나 플랜핏 2.9만 리뷰가 1위)
- 광고 그룹 2 — 일반 헬스, 정확 일치, 최대 CPT ₩600: 헬스 루틴 · 운동 루틴 · PT · 헬스 PT · 퍼스널 트레이닝 · 헬스 트레이너
- 광고 그룹 3 — 발굴, 검색 매치 + 확장 일치, 최대 CPT ₩400: 위 키워드의 확장. 매주 검색어 리포트에서 설치가 난 검색어를 1·2 그룹 정확 일치로 옮기고, 무관한 것은 제외 키워드로.
- 제외 키워드(시작부터): 필라테스 · 요가 · 다이어트 식단 · 칼로리 · 만보기 · 러닝 · 트레이너 구인 · 헬스장 예약 · 회원 관리
- 경쟁사 브랜드 입찰(플랜핏 등)은 하지 않는다 — 첫 테스트는 의도 검색어만.
- 광고 소재: 기본 제품 페이지(10-27 새 스크린샷). CPP 는 표본이 생긴 뒤.

## 측정(매일 루프가 본다)
- ASA 콘솔/API: 노출 · 탭 · 탭률 · 설치 · CPT · CPI, 키워드·검색어별.
- 앱(1.1.38~): RevenueCat 고객의 Apple Search Ads 귀속(캠페인·광고 그룹·키워드) → 체험 시작·결제. 운영 DB `app_events` 의 같은 날 가입·첫 세트·결제 화면.
- 기대(10-27 추정): 설치 40~70 → 체험 2~3. 근거 없는 낙관을 피하려고 판정은 아래 숫자로만.

## 판정
- 7일 차: CPI > ₩3,000 이면 입찰을 낮추거나 그룹 2·3 을 끈다. 탭률 < 3% 인 키워드는 끈다.
- 14일 차: 설치 30건 이상인데 체험 0 → 광고 중단, 퍼널(첫 운동·결제 화면)부터 고친다. 체험 2건 이상 → 체험→결제 전환을 7일 더 보고 예산 2배(하루 ₩20,000)와 일본 캠페인(AIパーソナルトレーナー·筋トレ 相談 계열)을 검토.

## 대표 손이 필요한 것(Claude 가 할 수 없는 것: 계정 생성·결제수단)
1. searchads.apple.com 에서 **Advanced** 계정 만들기(개발자 계정과 같은 Apple ID 권장) → 결제수단 등록 → 국가 한국.
2. 계정 설정 → 사용자 관리에서 API 역할(API Account Manager) 사용자 초대 또는 본인에게 API 권한 → 계정 설정 → API 에 **Claude 가 만들어 줄 공개 키**를 붙여 넣으면 clientId · teamId · keyId 가 나온다 → `kw add liftupai-asa` 로 세 값(+Claude 가 만든 개인 키)을 저장.
3. 그 뒤 캠페인 생성·키워드·입찰·매일 조정·보고는 Claude 가 Search Ads API(v5)로 한다. 2가 번거로우면 1만 하고 위 구성대로 콘솔에서 캠페인을 만들어 두면, 숫자는 대표가 주는 캡처나 리포트로 본다.
